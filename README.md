# URL Shortener
##### A simple URL shortener service built using Node.js and Express. It maps long URLs to unique short codes and handles redirection. The project includes basic URL normalization, duplicate detection, and validation to ensure consistent and reliable behavior

## Cloning the repo:
### 1.
```
git clone https://github.com/AnkuThakur704/urlShortener

```
### 2.
```
npm i

```
### 3.
```
npm run dev

```
